# 使い方

clone前にgit-lfsをインストールしてください

## インストール
uv をインストールしてください
```shell
curl -LsSf https://astral.sh/uv/install.sh | sh
```

## テキスト会話の生成

ollamaをインストールし、使いたいモデル（gpt-oss:20b, gpt-oss:120b）を起動してください。  
https://cookbook.openai.com/articles/gpt-oss/run-locally-ollama

以下でテキスト対話を生成できます
```shell
uv run generate_text_dialog.py
```

`output/transcript` にテキスト対話が生成されます

### オプション
- `--n`: 生成する対話数を指定 (デフォルト: 1)
- `--turns`: 対話の最大ターン数を指定 (デフォルト: 20)
- `--model`: 生成に使うモデル（デフォルト: gpt-oss:20b）

## 音声対話の生成

テキスト対話生成後、以下で音声対話に変換できます
```shell
uv run generate_audio_dialog.py
```

`output/audio` に音声対話が生成されます

### vitsモデルを追加する場合
`vits_model/` に config.json, style_vectors.npy と safetensorを配置してください

## データ作成手順

### 概要

テキスト対話の生成 → 音声対話への変換 → 強制アライメント の3段階でデータを作成します。

```
generate_text_dialog.py  →  generate_audio_dialog.py（内部でforced_alignment）
       ↓                              ↓                          ↓
 output/text/*.tsv          output/audio/*.mp3         output/timestamps/*.json
```

---

### ステップ1: テキスト対話の生成（`generate_text_dialog.py`）

#### 使用モデル

- **LLM**: `gpt-oss:20b`（デフォルト）/ `gpt-oss:120b`
- **実行環境**: Ollama経由でローカル実行（OpenAI互換API）

#### 生成パラメータ

- `--n`（デフォルト: 10,000）: 生成する対話数
- `--turns`（デフォルト: 20）: 1対話あたりの最大発話数
- `--model`（デフォルト: `gpt-oss:20b`）: 使用するLLMモデル
- `--max-retries`（デフォルト: 3）: JSONパース失敗時の最大リトライ回数
- `temperature`（デフォルト: 0.9）: 生成の多様性（コード固定値）
- `max_tokens`（デフォルト: 4,096）: 1回の生成における最大トークン数（コード固定値）

#### 対話タイプ

以下の20種類からランダムに選択されます。

1. レストラン予約
2. 天気案内（現在/今日/週）
3. 時刻表検索（電車/バス）
4. 乗換案内（最短/安い/本数）
5. ホテル予約（条件・日付・人数）
6. フライト情報（便名/遅延/到着）
7. タクシー配車/配車アプリ連携
8. 商品検索・価格比較（買い物）
9. 返品/返金手続きサポート
10. カレンダー予定の作成/確認
11. リマインダー設定/管理
12. ニュース要約と深掘りQA
13. 一般知識QA（百科/豆知識）
14. 翻訳（短文/用途指定）
15. 道案内・住所/地図検索
16. サブスク解約/プラン変更支援
17. 技術サポート（簡易トラブルシュート）
18. 健康/病院予約（科/時間/場所）
19. 家事タスク計画（買い物リスト等）
20. 旅行計画（行程/見どころ/予算）

#### 出力形式

- 場所: `output/text/dialog_<連番>_<タスク名>.tsv`
- 形式: TSV（タブ区切り）
- カラム:
  - `turn_index`: 発話の連番（1始まり）
  - `role`: 話者（`assistant` / `user`）
  - `content`: 発話テキスト
  - `task_type`: 対話タイプ
  - `seed_like`: 生成時の乱数値（参考値）
  - `timestamp`: 生成日時（`YYYYMMDD_HHMMSS`）
  - `model`: 使用したLLMモデル名

### ステップ2: 音声対話の生成（`generate_audio_dialog.py`）

#### 使用モデル

- **TTS（アシスタント音声）**: Style-BERT-VITS2（`youtube1`）、配置場所: `vits_model/youtube1/`
- **TTS（ユーザー音声）**: Style-BERT-VITS2（`youtube2`）、配置場所: `vits_model/youtube2/`
- **読み推定用BERT**: `ku-nlp/deberta-v2-large-japanese-char-wwm`（自動ダウンロード）
- **強制アライメント**: WhisperX（自動ダウンロード）

#### 音声パラメータ

- **サンプルレート**: 24,000 Hz（出力音声のサンプリング周波数）
- **ビット深度**: 16-bit（量子化ビット数）
- **チャンネル数**: 2ch（ステレオ）— 左ch = アシスタント、右ch = ユーザー
- **ラウドネス正規化**: -16.0 dBFS（ターンごとに正規化）
- **ターン間無音**: 400 ms（発話間に挿入する無音区間）
- **スタイル**: `Neutral`（TTSの発話スタイル）
- **出力フォーマット**: MP3（音声ファイル形式）

#### 強制アライメントパラメータ

- **言語**: `ja`（日本語）— アライメント対象言語
- **出力単位**: 文字（char）— タイムスタンプの粒度
- **時刻精度**: ミリ秒（小数点3桁）— タイムスタンプの丸め精度
- **アライメント用サンプルレート**: 16,000 Hz（WhisperX入力用に内部リサンプリング）

#### 出力形式

**音声ファイル** (`output/audio/<ファイル名>.mp3`)
- ステレオMP3（左ch: アシスタント、右ch: ユーザー）

**タイムスタンプファイル** (`output/timestamps/<ファイル名>.json`)
```json
[
  {
    "speaker": "A",
    "word": "こんにちは",
    "start": 0.123,
    "end": 0.456
  },
  ...
]
```

フィールドの説明:
- `speaker`: 話者ラベル（`A` = アシスタント、`B` = ユーザー）
- `word`: 文字（char単位）
- `start`: 発話開始時刻（秒）
- `end`: 発話終了時刻（秒）

---

### データ量の目安

- **総対話数**: 10,000 件
- **1対話あたりの最大発話数**: 20 発話
- **対話タイプ数**: 20 種類
- **1対話あたりの目安発話数**: 10〜20 発話（タスクによる）
- **テキストデータ合計（概算）**: 約 100,000〜200,000 発話
